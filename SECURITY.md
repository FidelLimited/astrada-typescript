# Security policy

## Report a vulnerability privately

If you find a security problem in the Astrada TypeScript SDK, report it through GitHub's private
vulnerability reporting: open the [Security tab](https://github.com/FidelLimited/astrada-typescript/security) of this repository and choose
**Report a vulnerability**. Only you and the Astrada team can see the report.

Never report a vulnerability in a public issue, a discussion or a pull request.

If the **Report a vulnerability** button is missing, write to developer@astrada.co with the subject
"Security report" and only a one-line summary (no details, card numbers or secrets). We answer with a
private way to send the rest.

## What to include

- The SDK version and your Node.js version.
- What the problem is, and what someone could do with it.
- The steps or a short code sample that show it.
- A request id from the API's response, if you have one.

Never include card numbers, access tokens, client secrets, webhook secrets or other credentials, not even
sandbox ones. If the report needs one to make sense, describe it (for example "a sandbox client secret").

## What happens next

We answer in the private report and keep you updated there until the problem is fixed. Fixes go into a
new release of the SDK.

For anything else, write to developer@astrada.co.
