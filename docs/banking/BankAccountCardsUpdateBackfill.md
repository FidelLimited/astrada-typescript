
# BankAccountCardsUpdateBackfill

Optional backfill configuration to import historical bank transactions for the linked card.

## Properties

### `startDate`

`Date`, optional

Start date for the backfill range in YYYY-MM-DD format.

### `endDate`

`Date`, optional

End date for the backfill range in YYYY-MM-DD format.
