
# BankInstitutionIncident

An outage or maintenance the bank data provider published for the bank.

## Properties

### `title`

`string`, optional

The provider's title for the incident.

### `startedAt`

`string`, optional

When the incident started, as the provider published it.

### `endedAt`

`string`, optional, can be `null`

When the incident ended, as the provider published it. Null while it is open.

### `status`

`string`, optional, can be `null`

The status on the provider's latest update to the incident.

### `update`

`string`, optional, can be `null`

The text of the provider's latest update to the incident.
