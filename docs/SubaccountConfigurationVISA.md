
# SubaccountConfigurationVISA

## Properties

### `countries`

`Array<string>`, required

List of contracted regional areas for Visa

One of: `USA`, `CAN`, `IRL`, `DEU`, `CZE`, `SWE`, `NLD`, `LTU`, `GBR`, `SVN`, `LUX`, `POL`, `SVK`, `HUN`, `ITA`, `ROU`, `FIN`, `DNK`, `MLT`, `LVA`, `GRC`, `AUT`, `HRV`, `CHE`, `NOR`, `ISL`, `FRA`, `ESP`, `ISR`, `SMR`, `VAT`, `AND`, `GIB`, `AUS`, `NZL`, `PRT`, `BEL`, `SGP`. A value the SDK does not know yet is passed through as a plain string.
