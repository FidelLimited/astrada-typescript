
# SubaccountConfigurationAMEX

## Properties

### `countries`

`Array<string>`, required

List of contracted regional areas for American Express

One of: `USA`, `CAN`, `GBR`, `ITA`, `SWE`, `AUS`, `NZL`. A value the SDK does not know yet is passed through as a plain string.
