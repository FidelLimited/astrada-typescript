
# NetworkBulkEnrollmentConsent

## Properties

### `acceptedAt`

`Date`, required

When the consent was recorded, which is the server time of the create request, in UTC, following ISO 8601 format.

### `version`

`string`, required

The version of the consent wording that was accepted, as sent by the client (for example `kickoff-consent-v1`).
