
# BinLookupWarning

A note about the answer, with a code to branch on.

## Properties

### `code`

`string`, required

A stable code for programs to branch on. New codes may be added; ignore codes you
don't recognize.


One of: `ISSUER_COUNTRY_NOT_CONFIRMED`. A value the SDK does not know yet is passed through as a plain string.

### `message`

`string`, required

A human-readable explanation. The wording may change.
