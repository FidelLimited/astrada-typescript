
# CardholderUpdateParamsCorporate

The corporate entity that this cardholder is associated with. `legalEntity` is set by the card network and cannot be changed here: it is ignored if sent, and the stored value is kept.

## Properties

### `id`

`string`, optional

The company ID to store on the cardholder, the same value a network bulk feed supplies. See `cardholder.corporate.id`.

### `employeeId`

`string`, optional

The unique identifier of the employee

### `alternativeEmployeeId`

`string`, optional

An alternative employee identifier, typically configured for specific enterprise integrations.
