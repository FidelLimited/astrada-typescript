
# SubaccountConfigurationMASTERCARD

## Properties

### `countries`

`Array<string>`, required

List of contracted regional areas for Mastercard

One of: `USA`, `CAN`, `GBR`, `IRL`, `SWE`, `DEU`, `NLD`, `DNK`, `ITA`, `POL`, `FIN`, `BEL`, `ESP`, `FRA`, `PRT`, `AUT`, `GRC`, `MLT`, `NOR`, `CHE`, `ISR`, `AUS`, `NZL`, `SGP`. A value the SDK does not know yet is passed through as a plain string.
