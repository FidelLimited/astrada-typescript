
# NetworkBulkEnrollmentSummaryLinks

## Properties

### `self`

[Link](Link.md), required

The open kickoff (`/network-bulk-enrollments/{id}`). A token with
`network-bulk-enrollments:read` or `network-bulk-feeds:read` can follow it to the
full enrollment; any other token gets `403`.
