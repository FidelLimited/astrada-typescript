# Contributing

This repository is a copy. The Astrada TypeScript SDK is built and released from a private repository at
Astrada, and each release replaces the files here, so pull requests to this repository are not merged.

What helps us most:

- **A bug**: [open a bug report](https://github.com/FidelLimited/astrada-typescript/issues/new?template=bug_report.yml) with the SDK version, the steps
  and what you expected. We fix it in the private repository and the fix arrives in the next release.
- **An idea or a missing feature**: [open a feature request](https://github.com/FidelLimited/astrada-typescript/issues/new?template=feature_request.yml).
- **A security problem**: follow [SECURITY.md](SECURITY.md). Do not open an issue.
- **A question about the API or your account**: write to developer@astrada.co, or read the guides at
  [docs.astrada.co](https://docs.astrada.co).

If you already have a fix, describe it in the issue (a short code sample is welcome). Never paste card
numbers, tokens or secrets into an issue.
